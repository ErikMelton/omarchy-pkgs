## Limits

Physical microphones/speakers, noisy-room accuracy, Omawake cold graphical-login autostart, accelerator device placement and aarch64 execution were not tested. The packages declare only x86_64; OpenVINO/CUDA are optional external runtimes. Omawake's native model-license restriction remains intact; its pinned archive was an isolated review fixture and no model weights are published. `setup systemd --status` distinguishes app-installed user units from package-owned units; actual packaged service lifecycle and active-setup restart were tested directly. Archive hashes bind the reviewed binary bytes but do not prove upstream binary reproducibility. Signed edge publication remains a post-merge task.

All images are actual worker-compositor captures; none are generated or retouched. The coordinator opened the key captures and cross-checked them against process paths, artifact identities, command results and journals. The bundle includes logs, images, generated audio and hashes, not model weights, credentials or release binaries. `SHA256SUMS` covers the evidence files. Git commit links provide immutable evidence; retention is normal repository retention with no expiring download tickets. [Both review workers were destroyed](review/cleanup.md). No merge was performed.
